## Why this matters

`docs/architecture.txt` is the ASCII overview of the library. It still describes
the old design: shaping by "Pango/FT2", "default → Pango/FT2/cgo", and swapped
files (`context.go`, `renderer.go`, `pango.go`) that do not exist. The native
path is now pure-Go `go-text/typesetting` with no cgo, and WASM uses Canvas2D.
`CLAUDE.md` (the agent guide) was corrected in #179. This file was not.

`docs/plans/pango-free-linux.md` and `docs/plans/shaped-glyph-stream.md` are old
design plans that have shipped. They read as current instructions ("All FT+HB
code lives in `*_android.go` files"). A reader, or a coding agent, can take them
as the current state.

`docs/diagrams/go-glyph-architecture.{html,json}` are already correct ("Root
module go-glyph (pure-Go, no cgo)"). Do not touch them.

  `renderer_wasm.go`. Layout is `layout_ft.go` and `layout_wasm.go`. Font
  discovery is `discover_<os>.go`.
- Packages: `accessibility/`, `ime/`, `internal/genemoji/`, `tools/lint`,
  `tools/docs`, `examples/`. `backend/ebitengine` is its own module.
